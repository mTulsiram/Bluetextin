GIMP

Linux · Productivity · Free & Open Source

GNU Image Manipulation Program — a professional image editor for Linux.

App Details

  • License: GPLv3
  • Platform: Linux
  • More Info: gimp.org

Overview

GIMP is the go-to raster image editor on Linux. It supports layers, masks, color spaces, scripts, and an enormous plugin library. Scripting with Script-Fu or Python automates repetitive editing tasks.

Available in every Linux distro's repos and as a Flatpak. GIMP 3.x brings GEGL-based non-destructive editing and improved color management.
