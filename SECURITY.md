# Security Policy

## Supported versions

Bluetext.in is a static web platform. Security fixes are applied on the active `main` branch.

## Reporting a vulnerability

Please report security issues privately and do not open public issues for exploitable details.

Preferred channels:

- Contact page: https://www.bluetext.in/nav/security.html
- Email: codeon@bluetext.in

Include:

- Affected URL(s)
- Reproduction steps
- Impact description
- Screenshots or logs (if available)

You will receive acknowledgement as soon as possible, and validated issues will be addressed on priority.
