Data Rights Request

For GDPR/CCPA-compatible requests: access, correction, deletion, portability, and opt-out.

Available Request Types

Access

Request a summary of personal data associated with your interactions.

Correction

Request updates to incorrect or outdated personal information.

Deletion

Request deletion of eligible personal data, subject to legal constraints.

Portability

Request portable export of applicable personal data.

Opt-Out

Request opt-out from non-essential processing categories.
