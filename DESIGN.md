# Design System Notes

## Visual Foundation

- Bootstrap 5.3.8 is the base UI framework
- Project-specific CSS layers are imported through assets/css/main.css
- Shared logo mark is used in both header and footer

## Layout Behavior

- Sticky header at top for persistent navigation
- Main content expands to fill viewport
- Footer remains at bottom when content is short

## Header UX

- Multi-category navigation with dropdowns
- Global search modal
- Language selector
- Theme mode button
- Sign in / account modal actions
- Clear cache action for local troubleshooting

## Footer UX

- Company and Legal columns
- Direct links to policy pages
- compliance statement line:
	- © 2026 BlueTEXT. All tools execute client-side. Zero tracker policy.

## Accessibility Rules

- Use semantic headings and maintain heading order
- Ensure all controls have accessible labels
- Keep interactive items keyboard reachable
- Preserve visible focus styles
- Avoid text that relies on color only

## Content Page Conventions

- Every page should have title, description, h1, and at least one intro paragraph
- Keep language plain and scannable
- Avoid excessive visual noise on tool pages
- Use shared layout mounts on every page:
	- id="header-component"
	- id="footer-component"

## Translation Workflow

- Source text is extracted and translated to 20 major world languages by scripts/build.js --i18n
- Runtime language switching loads pre-compiled JSON dictionaries at assets/data/i18n/[lang]-dictionary.json, bypassing client-side CORS issues
- Site defaults to Dark Mode and English language on initial load

## Search Workflow

- Search index is generated by scripts/build.js --search
- Runtime search reads the generated JSON to cover all pages at scale

## Build Workflow

- Unified script: scripts/build.js
- Full run: npm run build
- Includes sitemap generation and build report output
