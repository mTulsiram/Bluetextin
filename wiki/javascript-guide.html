Modern JavaScript (ES6+) Guide

JavaScript controls the dynamic logic on Bluetext. All tools are built strictly in vanilla JS without massive framework overhead, ensuring fast loads and minimal memory footprints.

1. Variable Declarations

Avoid var. Use block-scoped declarations:

  • const: Default for references that will not be reassigned.
  • let: Use when variables need to be reassigned.

2. Asynchronous Operations

Use clean async/await syntax for asynchronous requests, promises, and file handling:

async function fetchToolData(url) {
  try {
    const response = await fetch(url);
    const data = await response.json();
    return data;
  } catch (error) {
    console.error("Fetch failed:", error);
  }
}

3. DOM Manipulation

Use standard DOM event listeners instead of inline attributes (e.g. onclick):

const btn = document.getElementById('actionBtn');
btn.addEventListener('click', () => {
  log("Button clicked!", "ok");
});
