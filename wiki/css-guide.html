CSS Developer Reference Guide

CSS (Cascading Style Sheets) controls the visual representation of web elements. This guide covers core styling standards used across the Bluetext utility suite.

1. Box Model

Every element in CSS is represented as a rectangular box. The box model consists of: Content, Padding, Border, and Margin.

/* Standard box-sizing rule used for predictable sizing */
* {
  box-sizing: border-box;
}

2. Flexbox

Flexbox layout provides efficient alignment and distribution of space among items in a container.

.container {
  display: flex;
  flex-direction: row;
  justify-content: space-between;
  align-items: center;
}

3. CSS Variables (Custom Properties)

Bluetext uses standard CSS variables inside themes.css to manage light and dark mode colors dynamically.

:root {
  --bg-main: #f4f7f9;
  --text-primary: #1a1a1a;
}
[data-theme="dark"] {
  --bg-main: #05070f;
  --text-primary: #f3f4f6;
}
